Дата выхода 22 декабря 1999
Версия Оригинал (Америка)

Порт классической игры, выпущенный в 1999 году. Версия сохраняет все дополнения из оригинального PC-релиза и работает в режиме 60 кадров в секунду во время игрового процесса.

Уникальной особенностью этого порта является поддержка периферийного устройства VMU (Visual Memory Unit), которое отображает текущее состояние здоровья персонажа: «Fine» (отлично), «Caution» (осторожно, без мигания при жёлтом здоровье и с миганием при оранжевом) и мигающее «Danger» (опасность) при низком уровне здоровья. Игроки должны использовать аналоговый стик для управления.

В японской версии порт получил подзаголовок Value Plus и поставлялся с демоверсией игры Code Veronica. В этой версии режимы 4th Survivor и To-Fu разблокированы по умолчанию, а режим Arrange Mode включает сложности Rookie, Expert и Nightmare Mode. Изменения также коснулись саундтрека: в порте отсутствуют треки «Left alone?» и «The buildup of suspense».
